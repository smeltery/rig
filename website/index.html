A few good questions

Before you jump in.

Do I need a model subscription?

You need access to a supported model provider. Use an Anthropic, OpenAI, Gemini, or OpenRouter API key, or sign in with a supported ChatGPT/Codex subscription. Provider charges and terms apply.

Does Rig run entirely on my machine?

The binary, tools, and saved sessions run locally. Your chosen model provider receives the conversation and relevant tool results. Rig does not add product telemetry.

Does Rig sandbox commands?

No. Run Rig in a VM or sandbox that controls filesystem, process, network, and credential access. Optional interactive tool confirmations are not a security boundary.

Can I adapt it to my project?

Yes. Add AGENTS.md instructions, reusable skills, and custom named phases. Rig is source-available under the PolyForm Shield license; see the license for its terms.
