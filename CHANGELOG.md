## [0.1.0] - 2026-10-07

### Added

- Interactive terminal coding agent with project instructions, reusable skills,
  named phases, visible tool activity, and coordinated subagents.
- Anthropic, OpenAI, Google Gemini, and OpenRouter providers, including OpenAI
  subscription sign-in.
- Local conversation persistence, session search and resume, headless runs,
  and local configuration diagnostics.
- Native Linux and macOS binaries for amd64 and arm64, with a checksum-verifying
  installer.
- User guides, configuration and architecture references, and a dark-themed
  website with Rig branding and social imagery.
- Locked Flox and Bun development tooling, matching Git hooks and CI checks,
  Markdown and Mermaid validation, and source line budgets.
- Automatic stable patch releases after successful main-branch CI.
